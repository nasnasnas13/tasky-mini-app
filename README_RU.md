# Tasky — первая версия Telegram Mini App

Tasky — минималистичный планировщик дня и трекер привычек на русском языке.

## Что уже работает

- Один общий список на выбранный день: обычные задачи и экземпляры привычек.
- Создание и редактирование обычных задач.
- Создание привычек с повторением ежедневно или в выбранные дни недели.
- Автоматическое создание отдельных задач привычки на будущие даты (горизонт — 180 дней, создаётся по мере открытия приложения).
- Отметка выполнения; выполненные карточки становятся серыми.
- Пастельные цвета.
- Недельная сетка привычек с возможностью отметить выполнение.
- Управление привычками, пауза/архивация через удаление (история сохраняется).
- Перетаскивание задач мышью и кнопки перемещения вверх/вниз для мобильного.
- История выполненного, серии для привычек.
- Экспорт/импорт резервной копии JSON.
- Telegram Web Apps SDK: приложение вызывает `ready()` и `expand()`, но также работает в обычном браузере.

## Ограничения текущей версии

1. Данные сохраняются в `localStorage` браузера / Telegram WebView на текущем устройстве. Они не синхронизируются между разными устройствами и могут исчезнуть при очистке данных приложения или браузера.
2. Нет аккаунтов, серверной базы данных и уведомлений. Уведомления специально оставлены на следующий этап.
3. Это MVP для личного тестирования, а не версия для публикации широкой аудитории.
4. Для общего запуска и синхронизации нужно добавить сервер, базу данных и проверку `Telegram.WebApp.initData` на серверной стороне. Не доверяйте `initDataUnsafe` для авторизации.

## Быстрый локальный запуск

### Вариант A — просто открыть файл

Откройте `index.html` в современном браузере. Основные функции работают локально. Telegram SDK вне Telegram будет недоступен, но приложение покажет веб-версию.

### Вариант B — локальный веб-сервер

Если установлен Python 3:

```bash
cd tasky_mini_app
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация в интернете через GitHub + Vercel

Telegram Mini App должен быть доступен по HTTPS. Один из простых способов — загрузить папку в GitHub и подключить репозиторий к Vercel.

1. Создайте аккаунт GitHub: https://github.com/ и войдите.
2. Создайте новый репозиторий, например `tasky-mini-app`.
3. Загрузите в него файл `index.html` (и, при желании, этот README). Для текущей статической версии сборка не требуется.
4. Откройте https://vercel.com/ и войдите через GitHub.
5. Нажмите **Add New → Project**, выберите репозиторий `tasky-mini-app` и импортируйте его.
6. В настройках проекта оставьте Framework Preset как **Other** (или Static / No framework, если такой пункт показан), Root Directory — `./`, Build Command — пустой, Output Directory — `.`.
7. Нажмите **Deploy**. Vercel выдаст URL вида `https://tasky-mini-app-....vercel.app`.
8. Откройте полученный URL в обычном браузере и проверьте, что страница загружается по HTTPS.

При последующих изменениях загрузите обновлённый `index.html` в GitHub — Vercel автоматически выполнит новый деплой.

## Подключение к Telegram через BotFather

1. Откройте Telegram и найдите официального бота `@BotFather`: https://t.me/BotFather.
2. Отправьте `/newbot` и следуйте вопросам: имя, затем уникальный username, оканчивающийся на `bot`.
3. Сохраните токен бота в надёжном месте. **Не вставляйте токен в `index.html`, GitHub или публичные сообщения.** Для этого фронтенд-прототипа токен вообще не нужен.
4. В `@BotFather` выберите `/mybots` → ваш бот → **Bot Settings** → **Configure Mini App** (названия пунктов могут немного отличаться) → включите Mini App и укажите URL Vercel.
5. Чтобы добавить кнопку внизу чата с ботом, используйте `/setmenubutton`, выберите своего бота, задайте текст, например `Открыть Tasky`, и вставьте HTTPS URL приложения.
6. Откройте чат с ботом и нажмите кнопку меню. Проверьте приложение на телефоне и в Telegram Desktop.

Официальная документация Telegram: https://core.telegram.org/bots/webapps

## Проверка перед использованием

- Создать обычную задачу, обновить страницу и проверить, что она сохранилась.
- Создать привычку на понедельник, среду и пятницу; открыть недельный раздел и проверить появления в нужных столбцах.
- Отметить среду как выполненную, перейти на другой день и убедиться, что там отдельная отметка.
- Изменить дни привычки и убедиться, что выполненная история не исчезла.
- Перетащить две задачи (или нажать стрелки) и проверить сохранение порядка после обновления.
- Сделать экспорт JSON, очистить тестовые данные и импортировать резервную копию.

## Что понадобится для следующей версии

- Backend API и база данных (например, PostgreSQL / Supabase).
- Проверка подписи `Telegram.WebApp.initData` на сервере.
- Привязка данных к Telegram user ID после проверки подписи.
- Синхронизация задач между устройствами.
- Надёжные напоминания через Telegram-бота (планировщик на сервере; одного фронтенда для отправки уведомлений недостаточно).
- Политика конфиденциальности и резервное копирование перед публичным запуском.
